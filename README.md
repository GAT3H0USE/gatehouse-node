# Gatehouse Node releases

Public signed binaries and container images for Gatehouse Node. The source repository remains private.

Download the [latest release](https://github.com/GAT3H0USE/gatehouse-node/releases/latest). Linux amd64 and arm64 packages, signed update archives, checksums, SPDX SBOMs and Cosign build provenance are included.

Container: `ghcr.io/gat3h0use/gatehouse-node:v0.1.1`. Verify signatures and provenance before installation.
