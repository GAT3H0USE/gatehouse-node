# Gatehouse Node releases

This repository distributes signed Gatehouse Node binaries. Application source is maintained separately in a private repository; source history is not copied here.

Release assets include Debian packages, update bundles, checksums, SBOMs, signatures and Cosign build provenance. Verify the complete release before installation.

Container images are distributed as `ghcr.io/h-gate/gatehouse-node`. Installers resolve the latest published release and then use its verified immutable image digest.

The first public release is being prepared. No installation assets are available until publication finishes.
